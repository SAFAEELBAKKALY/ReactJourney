# Sound Pads

A grid of interactive pads that can be toggled on and off, built with React as part of my [React Journey](../../) learning project.

## Preview

![Sound Pads Preview](<img width="1303" height="625" alt="image" src="https://github.com/user-attachments/assets/227990a8-935b-428e-bee6-7634c5eca55c" />)

## About

This mini-project practices React state. Each pad is generated from a data array with `.map()` and rendered by a reusable `Pad` component. Clicking a pad toggles it between "on" and "off", and the visual change (color and opacity) is driven entirely by state.

## Concepts Practiced

- `useState` to store and update the pads
- Passing data and handlers to child components with props
- Rendering lists with `.map()` and `key`
- Updating state immutably (spread operator and the previous-state callback form)
- Inline styles and conditional class names

## Tech Stack

- React
- Vite
- CSS
