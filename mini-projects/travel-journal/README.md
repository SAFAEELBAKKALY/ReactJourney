# Travel Journal

A digital travel journal built with React, displaying trip entries with images, locations, dates, and descriptions — part of my [React Journey](../../) learning project.

## Preview



## About

This mini-project practices building and rendering multiple React components, each representing a travel entry with a photo, location marker, title, date range, and description.

## Tech Stack

- React
- Vite
- CSS

## Getting Started

```bash
npm install
npm run dev
```
